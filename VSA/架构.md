# VSA 架构（AD9361 + Zynq，400 MHz ~ 6 GHz）

> 方案：**AD9361 + Zynq 整板 + USB/网口**，不画 RF/ADC/FPGA 板。
> 分析带宽 **56 MHz**，覆盖绝大多数现实信号；WiFi 80/160 MHz 除外。

---

## 1. 目标

| 项 | 目标 |
|---|---|
| 频率 | **400 MHz ~ 6 GHz**（AD9361：70M~6G） |
| 分析带宽 | **≤56 MHz** |
| 测量 | I/Q、EVM、星座、频谱、占用带宽、CCDF |
| 输入 | 50 Ω，SMA，0~30 dB 衰减 |
| 输出 | PC 显示 / 存 I/Q |

> 56 MHz 覆盖：GSM、蓝牙、Zigbee、LTE、WiFi 20/40、LoRa。
> 不覆盖：WiFi 80/160、5G NR 100 MHz。

---

## 2. 方案

| 部分 | 选型 | 说明 |
|---|---|---|
| 收发器 | **AD9361** | 2×2，70M~6G，56 MHz 带宽 |
| 处理器 | **Zynq 7020** | ARM + FPGA，跑 Linux |
| 接口 | **USB / 网口** | 连 PC |
| 前端 | 衰减器 + 滤波 | 400M~6G |
| 软件 | libiio + Python | 采集/FFT/解调 |

**不画 AD9361 板**，买整板即可。

---

## 3. 系统框图

```
RF IN ──► 衰减器 ──► 滤波 ──► AD9361 RX
                                  │
                              Zynq（DDC/抽取）
                                  │
                             USB / 网口
                                  │
                                PC
                          （FFT / 解调 / EVM）

AD9361 内部 LO（70M~6G）
```

---

## 4. 硬件

- **AD9361 + Zynq 7020 整板**（带 SMA、USB/网口）。
- 外部**衰减器**（0~30 dB，400M~6G）。
- 外部**预选滤波**（可选）。
- SMA 线、50 Ω 负载、校准件。
- 外壳/屏蔽（可选）。

> 如果买 FMC 子卡，还要一块 Zynq 载板；整板最省事。

---

## 5. 软件

### 板上

- Linux + **libiio**。
- AD9361 驱动。
- 可选：FPGA 做 DDC/抽取/FFT。

### PC

- **pyadi-iio** 采集 I/Q。
- numpy/scipy 做 FFT、滤波、解调。
- PyQt5 + matplotlib 显示。
- 保存 `.cf32` / `.wav`。

---

## 6. 指标

| 指标 | 说明 |
|---|---|
| 分析带宽 | ≤56 MHz |
| ADC | 12 位 |
| 动态范围 | 取决于前端/增益 |
| 相位噪声 | AD9361 LO |
| EVM | 受 SNR/相位噪声/线性度影响 |
| 镜像抑制 | I/Q 校准 |

---

## 7. 校准

- **I/Q 幅度/相位不平衡**：抑制镜像。
- **DC 偏置**：去直流。
- **幅度/频率响应**：用已知信号校准。
- **参考电平**：dBm 标定。

---

## 8. 分阶段

| 阶段 | 内容 | 产出 |
|---|---|---|
| M1 | 板子点亮，采 I/Q | 看到单音 |
| M2 | FFT/频谱 | 简易 SA |
| M3 | QAM/OFDM 解调 | 星座、EVM |
| M4 | 前端/校准 | 幅度准确，和商用对比 |

## 10. 风险

- **56 MHz 上限**：WiFi 80/160 测不了。
- **AD9361 板卡资料**：BSP/镜像/驱动要确认。
- **前端过载**：必须加衰减/保护。
- **EVM 校准**：I/Q 不平衡、相位噪声。
- **网口/USB 吞吐**：56 MHz I/Q 数据率约 56M×4B=224 MB/s，USB2 不够，需 USB3/网口。

---

## 11. 和 SA / VNA 的关系

- **SA**：同一块 AD9361 板，RX + FFT。
- **VNA**：AD9361 的 TX 做源，RX 接收；加**定向耦合器**做 1 端口 S11；2 端口加开关。
- 三套仪器可以共用一块 AD9361 + Zynq 板，只是前端/软件不同。
