# VNA 架构（2 端口，400 MHz ~ 6 GHz）

> 目标：2 端口 VNA，覆盖 400 MHz~6 GHz（含 WiFi 5G），测 S11/S21/S12/S22，12 项校准，导出 `.s2p`。
> 单源（ADF4355）+ 单种检波（ADL5380 ×4），比 1 MHz 版本简单很多。

---

## 1. 目标

| 项 | 目标 |
|---|---|
| 频率 | **400 MHz ~ 6 GHz** |
| 端口 | **2 端口**（S11/S21/S12/S22） |
| 校准 | **12 项**（SOLT）+ I/Q 不平衡 |
| 输出 | `.s2p`、Smith、插损/回损/相位 |
| 对比 | LiteVNA / NanoVNA V2 Plus4 |

---

## 2. 系统框图

```
ADF4355（54M~6.8G）
   │
   ├── 功分 ──► 源开关 ──► 端口1 耦合器 ──► DUT ──► 端口2 耦合器
   │                          │                        │
   │                       a1 / b1                  a2 / b2
   │                          │                        │
   │                    ADL5380#1/#2             ADL5380#3/#4
   │                       I/Q                      I/Q
   │                          │                        │
   └── LO 功分 + 放大 ────────┴────────────────────────┘
                              │
                        STM32H743（多路 ADC）
                              │
                            PC（12 项校准 + 画图）
```

- 源：ADF4355，覆盖 400M~6G。
- 源开关：把源接到端口 1 或端口 2。
- 耦合器：2 个，覆盖 400M~6G。
- 检波：**4 片 ADL5380**（a1、b1、a2、b2）。
- LO：源功分 + 放大，供 4 片 ADL5380。

## 3. 硬件选型

| 模块 | 型号 | 说明 |
|---|---|---|
| 信号源 | **ADF4355** | 54 MHz~6.8 GHz，SPI |
| 源开关 | SPDT RF 开关 | 400M~6G |
| 定向耦合器 | 2 个，400M~6G | 方向性越好，测量下限越低 |
| 幅度/相位检测 | **ADL5380 ×4** | 400 MHz~6 GHz，I/Q |
| LO 功分 | 4 路功分 | 400M~6G |
| LO 放大 | 增益块 | 补偿功分损耗 |
| MCU | **STM32H743** | 3 个 ADC、SPI、USB |
| 电源 | LDO | 模拟部分独立 LDO + 磁珠 |
| 接口 | SMA 边装 | 50 Ω |
| 屏蔽 | 屏蔽罩 | 5 GHz 必备 |

> 4 片 ADL5380 = 8 路模拟输出（I/Q ×4）。H743 的 3 个 ADC 可以扫描采样；I/Q 最好同时采。

## 4. 2 端口测量

源接端口 1：

```
S11 = b1 / a1
S21 = b2 / a1
```

源接端口 2：

```
S22 = b2 / a2
S12 = b1 / a2
```

4 片 ADL5380 同时测 a1、b1、a2、b2，源开关切换两次即可。

每个 S 参数都是复数（幅度 + 相位）。

---

## 5. 校准（12 项）

12 项误差模型：

- 正向：方向性、源匹配、反射跟踪、负载匹配、传输跟踪、隔离。
- 反向：同样 6 项。

校准件：**SOLT**（短路/开路/负载/直通）。

步骤：

1. 端口 1/2 分别接开路、短路、负载。
2. 两端口直通（thru）。
3. 解 12 项误差。
4. 测量时反算 S 参数。

5 GHz 还要：

- ADL5380 的 I/Q 幅度/相位不平衡校准。
- LO 泄漏/DC 偏置扣除。

## 6. 固件架构

```
main
 ├─ 初始化：SPI(ADF4355)、源开关、ADC、USB
 ├─ 扫频任务
 │   ├─ 设 ADF4355 频率、等锁定
 │   ├─ 源开关接端口1 → 采 a1/b1/a2/b2
 │   ├─ 源开关接端口2 → 采 a1/b1/a2/b2
 │   └─ 打包发送
 ├─ 12 项校准表（Flash）
 └─ 命令解析
```

- 扫频点数：201/401/801
- 每点平均：8~32 次
- 开关切换后等待稳定再采样

## 8. RF PCB 设计要点

- **4 层**：L1 RF / L2 GND（0.2 mm）/ L3 电源 / L4 控制
- 50 Ω 微带：0.2 mm 介质 → 约 **0.35 mm**
- 两个耦合器、4 路接收，**等长**
- 屏蔽罩：ADF4355、ADL5380、耦合器
- LO 走线屏蔽，防泄漏
- 源开关靠近耦合器，减少桩线
- 模拟电源独立 LDO + 磁珠
- 地平面完整，数字/模拟单点接地

## 11. 风险

- **4 片 ADL5380**：成本、功耗、8 路 ADC。
- **耦合器 400M~6G**：宽带耦合器难做/贵，方向性影响精度。
- **源开关**：插损、隔离、重复性。
- **5 GHz 布局/屏蔽**。
- **12 项校准**：工作量大，校准件质量。
- **LO 分配**：4 路 LO 的幅度/相位一致性。
