# VNA 实施步骤（2 端口，400 MHz ~ 6 GHz）

> 顺序：**先买模块做验证，再画板；板画完再买元件**。
> 先 1 端口，再 2 端口。

---

## Phase 0：准备（不买件）

- [ ] 确认指标：400 MHz~6 GHz、2 端口、12 项校准、`.s2p`
- [ ] 预算：约 **¥2000~3000**（模块约 ¥900~1950，元件/PCB 约 ¥800~1200）
- [ ] 工具：万用表、示波器（DS1202Z-E）、烙铁 + 热风、USB 线
- [ ] 软件：**Altium Designer**、STM32CubeIDE、Python（PyQt5 + matplotlib）
- [ ] 参考：LiteVNA / NanoVNA（对比用）

**验收**：指标、预算、工具、软件确认。

---

## Phase 1：软件选择（Altium Designer）

- [ ] EDA：**Altium Designer（AD）**
- [ ] 阻抗计算：AD Layer Stack Manager / Saturn PCB
- [ ] 固件：STM32CubeIDE
- [ ] 上位机：Python + PyQt5 + matplotlib
- [ ] 仿真（可选）：ADS/HFSS（6 GHz 才需要）

**验收**：AD 能新建 4 层工程，Layer Stack Manager 可用。

> 只买模块，不买板上的芯片/元件。

**验收**：模块到货，能点亮。

---

## Phase 3：桌面模块验证（M1）

### 3.1 源

- [ ] ADF4355 接 5 V，SPI 接 H743
- [ ] 写最小 SPI 程序，设 1 GHz
- [ ] 读锁定指示（LD）
- [ ] 用 ADL5380 或二极管检波器确认有 RF 输出

### 3.2 1 端口 S11

- [ ] ADF4355 → 功分 → 耦合器 → DUT
- [ ] 耦合器前向 → ADL5380 #1（入射）
- [ ] 耦合器反向 → ADL5380 #2（反射）
- [ ] 源功分一路做 LO，接两片 ADL5380
- [ ] H743 采 I/Q，算 `A`、`B`、`|S11|`、相位
- [ ] 测开路/短路/50 Ω，和 LiteVNA 对比

**验收**：

- 开路：`|S11|` 接近 1
- 短路：`|S11|` 接近 1，相位差 180°
- 50 Ω：`|S11|` 接近 0
- 和 LiteVNA 趋势一致

## Phase 4：原理图（Altium Designer）

- [ ] 源：ADF4355（模块或芯片）
- [ ] 功分：RF 功分器
- [ ] 源开关：SPDT
- [ ] 耦合器 ×2
- [ ] ADL5380 ×4
- [ ] LO 功分 + 放大
- [ ] H743：SPI、ADC、USB、SWD
- [ ] 电源：LDO、磁珠、去耦
- [ ] SMA、屏蔽罩、测试点
- [ ] 4 层叠层：L1 RF / L2 GND 0.2 mm / L3 电源 / L4 控制
- [ ] 用 AD 库/自建库（SMA、ADL5380、ADF4355、H743）
- [ ] 建网络类/差分对（如有）

**验收**：ERC 通过，网络表正确。

---

## Phase 5：PCB（Altium Designer）

- [ ] AD Layer Stack Manager：4 层，L1-L2 0.2 mm
- [ ] AD 阻抗剖面/计算：50 Ω 微带 0.35 mm
- [ ] 4 层：L1 RF / L2 GND（0.2 mm）/ L3 电源 / L4 控制
- [ ] 50 Ω 微带：0.35 mm
- [ ] 设计规则：间距、线宽、过孔、差分
- [ ] 布局：源/耦合器/ADL5380 靠近端口，等长
- [ ] 地平面完整，过孔缝合
- [ ] SMA 边装，地脚多过孔
- [ ] 屏蔽罩焊盘
- [ ] DRC、3D 检查
- [ ] 导出 Gerber/ODB++（AD）

**验收**：DRC 0 错，3D 无干涉，Gerber 检查。

---

## Phase 6：元件采购（画完板再买）

- [ ] PCB 打样（4 层，按叠层）+ 钢网
- [ ] ADL5380 芯片 ×4
- [ ] 定向耦合器 ×2
- [ ] SPDT RF 开关
- [ ] 4 路功分 + 增益块
- [ ] LDO、磁珠、阻容
- [ ] SMA、屏蔽罩

**验收**：PCB 和元件到货。

---

## Phase 7：焊接 / 上电

- [ ] 先焊电源，测电压
- [ ] 再焊 H743、ADF4355、ADL5380
- [ ] 热风焊 LFCSP，注意散热焊盘
- [ ] 上电测电流，别冒烟

**验收**：电源正常，MCU 能下载，源能锁定。

---

## Phase 8：固件

### 8.1 驱动

- [ ] ADF4355 SPI 驱动（寄存器 0~12）
- [ ] 源开关控制
- [ ] ADC：8 路 I/Q，DMA + 平均
- [ ] USB CDC 协议

### 8.2 扫频

- [ ] 频率表（201/401 点）
- [ ] 每点：设频 → 等锁定 → 设开关 → 延时 → 采样
- [ ] 打包发送

### 8.3 1 端口 → 2 端口

- [ ] 先做 S11
- [ ] 再加源开关、S21/S12/S22

**验收**：扫频数据能连续输出。

---

## Phase 9：校准

### 9.1 1 端口 OSL

- [ ] 开路/短路/负载，采 3 组数据
- [ ] 解 Ed、Es、Er
- [ ] 反算 Γ，验证已知负载

### 9.2 2 端口 12 项

- [ ] SOLT：短路/开路/负载/直通
- [ ] 解 12 项误差
- [ ] 验证 S11/S21/S12/S22

### 9.3 5 GHz 附加

- [ ] I/Q 幅度/相位不平衡校准
- [ ] LO 泄漏/DC 偏置扣除

**验收**：校准后 50 Ω 的 `|S11|` < -30 dB，直通 `|S21|` 接近 0 dB。

## 关键风险

- ADL5380 LFCSP 焊接。
- 400M~6G 耦合器难买/贵。
- 5 GHz 布局/屏蔽。
- 12 项校准工作量大。
- 模块验证和整板可能有差异，需留调试余量。
