# VNA 实施步骤（2 端口，400 MHz ~ 6 GHz）

> 按阶段推进，每个阶段有验收点。先模块验证，再画板；先 1 端口，再 2 端口。

---

## Phase 0：准备

- [ ] 确认指标：400 MHz~6 GHz、2 端口、12 项校准、`.s2p`
- [ ] 预算：约 ¥1500~2500
- [ ] 工具：万用表、示波器（DS1202Z-E）、烙铁 + 热风、USB 线
- [ ] 软件：EasyEDA Pro、STM32CubeIDE、Python（PyQt5 + matplotlib）
- [ ] 参考：LiteVNA / NanoVNA（对比用）

**验收**：指标、预算、工具齐。

---

## Phase 1：采购 / BOM

### 模块（先买，用于验证）

- [ ] ADF4355 模块（带 SMA，SPI）
- [ ] ADL5380 模块 / 转接板 ×2（先做 1 端口）
- [ ] 定向耦合器 400M~6G ×1（或电阻桥）
- [ ] STM32H743 核心板
- [ ] SMA 线、50 Ω 负载、开路/短路校准件
- [ ] 屏蔽罩、杜邦线、电源

### 后面画板再买

- [ ] ADL5380 芯片 ×4
- [ ] 定向耦合器 ×2
- [ ] SPDT RF 开关
- [ ] 4 路功分 + 增益块
- [ ] LDO、磁珠、阻容

**验收**：模块到货，能点亮。

> 注意：ADL5380 是 LFCSP 封装，不能面包板；先买模块或做转接板。

---

## Phase 2：桌面模块验证（M1）

### 2.1 源

- [ ] ADF4355 接 5 V，SPI 接 H743
- [ ] 写最小 SPI 程序，设 1 GHz
- [ ] 读锁定指示（LD）
- [ ] 用 ADL5380 或二极管检波器确认有 RF 输出

### 2.2 1 端口 S11

- [ ] ADF4355 → 功分 → 耦合器 → DUT
- [ ] 耦合器前向 → ADL5380 #1（入射）
- [ ] 耦合器反向 → ADL5380 #2（反射）
- [ ] 源功分一路做 LO，接两片 ADL5380
- [ ] H743 采 I/Q，算 `A`、`B`、`|S11|`、相位
- [ ] 测开路/短路/50 Ω，和 LiteVNA 对比

**验收**：

- 开路：`|S11|` 接近 1
- 短路：`|S11|` 接近 1，相位差 180°
- 50 Ω：`|S11|` 接近 0
- 和 LiteVNA 趋势一致

## Phase 3：原理图

- [ ] 源：ADF4355（模块或芯片）
- [ ] 功分：RF 功分器
- [ ] 源开关：SPDT
- [ ] 耦合器 ×2
- [ ] ADL5380 ×4
- [ ] LO 功分 + 放大
- [ ] H743：SPI、ADC、USB、SWD
- [ ] 电源：LDO、磁珠、去耦
- [ ] SMA、屏蔽罩、测试点

**验收**：ERC 通过，网络表正确。

---

## Phase 4：PCB

- [ ] 4 层：L1 RF / L2 GND（0.2 mm）/ L3 电源 / L4 控制
- [ ] 50 Ω 微带：0.35 mm
- [ ] 布局：源/耦合器/ADL5380 靠近端口，等长
- [ ] 地平面完整，过孔缝合
- [ ] SMA 边装，地脚多过孔
- [ ] 屏蔽罩焊盘
- [ ] DRC、3D 检查
- [ ] 导出 Gerber

**验收**：DRC 0 错，3D 无干涉，Gerber 检查。

---

## Phase 5：打样 / 焊接

- [ ] 打样（4 层，1.6 mm 或按叠层）
- [ ] 钢网 + 锡膏
- [ ] 先焊电源，测电压
- [ ] 再焊 H743、ADF4355、ADL5380
- [ ] 热风焊 LFCSP，注意散热焊盘
- [ ] 上电测电流，别冒烟

**验收**：电源正常，MCU 能下载，源能锁定。

---

## Phase 6：固件

### 6.1 驱动

- [ ] ADF4355 SPI 驱动（寄存器 0~12）
- [ ] 源开关控制
- [ ] ADC：8 路 I/Q，DMA + 平均
- [ ] USB CDC 协议

### 6.2 扫频

- [ ] 频率表（201/401 点）
- [ ] 每点：设频 → 等锁定 → 设开关 → 延时 → 采样
- [ ] 打包发送

### 6.3 1 端口 → 2 端口

- [ ] 先做 S11
- [ ] 再加源开关、S21/S12/S22

**验收**：扫频数据能连续输出。

---

## Phase 7：校准

### 7.1 1 端口 OSL

- [ ] 开路/短路/负载，采 3 组数据
- [ ] 解 Ed、Es、Er
- [ ] 反算 Γ，验证已知负载

### 7.2 2 端口 12 项

- [ ] SOLT：短路/开路/负载/直通
- [ ] 解 12 项误差
- [ ] 验证 S11/S21/S12/S22

### 7.3 5 GHz 附加

- [ ] I/Q 幅度/相位不平衡校准
- [ ] LO 泄漏/DC 偏置扣除

**验收**：校准后 50 Ω 的 `|S11|` < -30 dB，直通 `|S21|` 接近 0 dB。

## 关键风险

- ADL5380 LFCSP 焊接。
- 400M~6G 耦合器难买/贵。
- 5 GHz 布局/屏蔽。
- 12 项校准工作量大。
- 改板成本/时间。
