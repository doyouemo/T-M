# SA 架构（频谱仪，400 MHz ~ 6 GHz）

> 目标：做一台 400 MHz~6 GHz 的频谱仪，能看频谱、谐波、杂散、占用带宽。
> 和 VNA 共用 ADF4355 + ADL5380 的思路：**I/Q 下变频 + FFT**。

---

## 1. 目标

| 项 | 目标 |
|---|---|
| 频率 | **400 MHz ~ 6 GHz** |
| 显示 | 幅度 vs 频率（dBm） |
| RBW | 10 kHz ~ 1 MHz（FFT 可调） |
| 动态范围 | 60~80 dB |
| 输入 | 50 Ω，SMA |
| 衰减 | 0~30 dB 步进 |
| 输出 | PC 显示 / 存轨迹 |

---

## 2. 架构选择

| 架构 | 优点 | 缺点 |
|---|---|---|
| **扫频超外差 + 对数检波** | 动态范围大、经典 | RBW 由滤波器定，改起来麻烦 |
| **I/Q 下变频 + FFT** | 灵活，能兼做 VSA；复用 ADL5380 | 动态范围受 ADC 限制 |
| SDR（AD9361）+ FFT | 宽带、简单 | 另一套平台 |

**推荐：I/Q 下变频 + FFT**，和 VNA 共用 ADL5380 + ADF4355。

---

## 3. 系统框图

```
RF IN ──► 衰减器 ──► 预选滤波 ──► ADL5380（RF）
                                      │
                                 I/Q 基带
                                      │
                                    ADC
                                      │
                                    FFT
                                      │
                                    PC

ADF4355（LO，扫频）──► ADL5380（LO）
```

- 输入先衰减，防大信号过载。
- 预选滤波抑制镜像/杂散（可选）。
- ADL5380 做下变频，输出 I/Q。
- ADC 采样，FFT 出频谱。
- 扫 LO，拼接多个 FFT 段，覆盖 400M~6G。

---

## 4. 器件选型

| 模块 | 型号 | 说明 |
|---|---|---|
| LO | **ADF4355** | 54M~6.8G，扫频 |
| 下变频 | **ADL5380** | 400M~6G，I/Q |
| 衰减器 | 数字步进衰减器 | 0~30 dB，0.5/1 dB 步进，400M~6G |
| 预选滤波 | 低通/带通 | 抑制镜像和带外 |
| ADC | H743 内部 12/16 位，或外部 14/16 位 | 采样率看 IF 带宽 |
| MCU | STM32H743 | FFT、USB |
| 输入保护 | 限幅二极管 | 防过载 |

> 如果只想做“扫频 SA”，可以用 **对数检波器（ADL5519/AD8318）** 替代 ADC+FFT，动态范围更大，但没有相位。

---

## 5. 关键指标

| 指标 | 说明 |
|---|---|
| **RBW** | FFT 分辨率 = 采样率 / 点数；或 IF 滤波器带宽 |
| **DANL** | 显示平均噪声电平，取决于噪声系数和 RBW |
| **相位噪声** | 由 ADF4355 决定 |
| **动态范围** | ADC 位数 + 衰减器 + 前端 |
| **镜像抑制** | 预选滤波 + I/Q 校准 |

---

## 6. 校准

- **频率校准**：LO + IF 的频率误差。
- **幅度校准**：衰减器、滤波器、ADC 的频率响应；用已知信号源。
- **I/Q 不平衡**：幅度/相位校正，抑制镜像。
- **参考电平**：0 dBm 对应 ADC 满量程的标定。

---

## 7. 固件架构

```
main
 ├─ 初始化：SPI(ADF4355)、衰减器、ADC、USB
 ├─ 扫频任务
 │   ├─ 设 LO 频率
 │   ├─ 采 I/Q（DMA + 平均）
 │   ├─ FFT（H743 DSP 或送 PC）
 │   └─ 拼接频谱段
 ├─ 校准表（Flash）
 └─ 命令解析
```

- 扫频点数：FFT 点数 1024/2048/4096。
- 每段 LO 固定，采一段 I/Q，FFT 后拼接。
- 衰减器按输入电平自动/手动切换。

## 8. PC 软件

- Python + PyQt5 + matplotlib
- 频谱显示、marker、RBW、span、参考电平
- 保存轨迹、导出 CSV
- 幅度/频率校准向导

## 9. RF PCB 设计要点

- **4 层**：L1 RF / L2 GND（0.2 mm）/ L3 电源 / L4 控制
- 50 Ω 微带：0.2 mm 介质 → 约 **0.35 mm**
- 衰减器、滤波器、ADL5380 靠近 SMA
- 屏蔽罩：ADL5380、ADF4355、衰减器
- LO 走线屏蔽，防泄漏
- 地平面完整，过孔缝合
- 输入保护/限幅

---

## 10. 分阶段

| 阶段 | 内容 | 产出 |
|---|---|---|
| M1 | 固定 LO，FFT 窄带 | 看到已知单音 |
| M2 | 扫 LO，拼接频谱 | 400M~6G 全段 |
| M3 | 衰减器 + 幅度校准 | 幅度准确 |
| M4 | PC 软件 + 对比 | 和 LiteVNA/信号源对比 |

## 12. 风险

- **ADL5380 基带带宽**：IF 带宽有限，窄带没问题，宽带要评估。
- **镜像抑制**：I/Q 不平衡会漏镜像。
- **动态范围**：ADC 位数和前端增益分配。
- **LO 相位噪声**：影响近端动态范围。
- **衰减器/滤波器**：400M~6G 宽带器件难找/贵。
